Rules

The rules Claude Code reads in DESIGN.md, in plain words.

  • Use the system's values only. Never type in a colour, size or corner by hand.
  • Apps use the named roles (page, row, control, text), not the grey ramp directly.
  • The accent appears only in the seven places shown above, and as the focus ring, the focus underside and the speckle's coloured flecks.
  • Focus is an accent ring on tiles and toggles, a cream fill with dark text on a coral underside on buttons, fields and picker rows, and a lifted row in lists.
  • Only one thing shows focus at a time.
  • Labels on the accent use its ink colour.
  • Green, yellow and red are for success, warning and error only.
  • System font only. Never add a web font.
  • Layouts adapt to the space they are given, never to a screen size, a device or an aspect ratio.
  • Nothing of Valve's is copied: no icons, logos, fonts or class names.
  • Build screens from the components before writing any new CSS.
  • Movement only marks focus or a change. The focus pulse stops after about five seconds. Everything works with reduced motion.

Two things to watch

  • Accent text is not readable enough on the control grey (with the default accent, 3.98:1, and text needs 4.5:1). Keep accent status text on the page or on a row, not on a focused row.
  • Muted text has the same problem on the control grey (3.12:1). When a row is focused, its muted text should step up to soft text.

The guidelines

  • Satin, never gloss.
  • Patterns live on the page ground and in progress fills only. Nothing you can select is ever patterned.
  • One border per element: no rims inside rings, no lips inside outlines.
  • One focus style per kind of element: cream on a coral underside for things you press, a coral ring for tiles, a lift for rows.
  • Cream is a neutral; the accent stays the only colour.
  • Only things you press move physically.
  • Every size is a multiple of 4 in its own unit (0.25rem if it grows with text, 4px if it does not) unless a listed exception applies.
  • Ask of every size: should it grow when the user makes text bigger? Yes is rem, no is px. Never set the root font size.
